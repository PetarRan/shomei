# Assets Folder

This folder contains images, logos, and other visual assets for the shōmei project.

## Usage

Place your images here and reference them in the main README.md like this:

```markdown
![Alt text](assets/your-image.png)
```

## Image Guidelines

- Use PNG or SVG for logos and screenshots
- Keep file sizes reasonable (< 1MB for screenshots)
- Use descriptive filenames
- Consider adding alt text for accessibility
