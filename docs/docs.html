shōmei docs

Complete guide to using shōmei for safe repository sanitization

Quick Start

Get up and running with shōmei in minutes

1. Install shōmei

pip install shomei

2. Initialize in your repository

cd /path/to/your/repo
shomei init

3. Process and sanitize

shomei process . --config config.yml

Commands Reference

shomei init

Initialize shōmei configuration in the current directory.

shomei init
# Creates ~/.shomei/config.yml with your personal details

shomei analyze <repo_path>

Analyze a repository to see what would be processed.

shomei analyze . --config config.yml
# Shows:
# - Commit analysis by author
# - Files that will be stripped/preserved
# - Repository statistics

shomei process <repo_paths...>

Process and sanitize one or more repositories.

# Process current directory
shomei process

# Process specific repositories
shomei process /path/to/repo1 /path/to/repo2

# Dry run (preview only)
shomei process --dry-run /path/to/repo

# Override personal details
shomei process --personal-email "you@example.com" --personal-name "Your Name" /path/to/repo

shomei contribute

Show information about contributing to shōmei.

shomei contribute

Configuration

Customize shōmei behavior with configuration files

Configuration File: ~/.shomei/config.yml

Personal Information

Your personal details for sanitized commits.

personal_name: "Your Name"
personal_email: "you@example.com"

Sanitization Settings

Control how files are processed.

sanitization:
  strip_files: true                    # Replace file contents with placeholder
  placeholder_text: "[STRIPPED]"       # Text to use as placeholder
  keep_structure: true                 # Preserve directory structure
  strip_file_extensions: [".py", ".js", ".ts", ".java", ".cpp", ".c", ".h", ".go", ".rs", ".php"]
  preserve_file_extensions: [".md", ".txt", ".yml", ".yaml", ".json", ".gitignore"]

Output Settings

Configure where and how output is generated.

output:
  directory: "./sanitized_repo"        # Output directory
  create_new_repo: true               # Create new git repository
  keep_branches: ["main", "master"]   # Branches to preserve

Usage Examples

Basic Repository Sanitization

Sanitize a single repository with default settings.

# Navigate to your repository
cd /path/to/corporate/repo

# Initialize shōmei (first time only)
shomei init

# Process the repository
shomei process .

# The sanitized version is now in ./sanitized_repo/

Multiple Repository Processing

Process multiple repositories at once.

# Process multiple repositories
shomei process /path/to/repo1 /path/to/repo2 /path/to/repo3

# Each gets its own sanitized output directory

Dry Run Analysis

Preview what will happen without making changes.

# Analyze what will be processed
shomei analyze . --config config.yml

# Preview the sanitization process
shomei process --dry-run .

Custom Configuration

Use a specific configuration file.

# Use custom config
shomei process . --config my_config.yml

# Override personal details
shomei process . --personal-email "work@example.com" --personal-name "Work Name"

Advanced Usage

Selective File Processing

Customize which files are stripped or preserved.

# In your config.yml
sanitization:
  strip_file_extensions: [".py", ".js", ".ts"]  # Strip these file types
  preserve_file_extensions: [".md", ".txt"]     # Keep these file types
  preserve_files: ["README.md", "LICENSE"]      # Always preserve these files
  strip_files: ["secrets.json", "config.env"]   # Always strip these files

Custom Placeholder Text

Use meaningful placeholder text for different file types.

# In your config.yml
sanitization:
  placeholder_text: "[CORPORATE_CONTENT_REMOVED]"
  
  # Or use different placeholders for different file types
  file_type_placeholders:
    ".py": "[PYTHON_CODE_STRIPPED]"
    ".js": "[JAVASCRIPT_CODE_STRIPPED]"
    ".md": "[DOCUMENTATION_PRESERVED]"

Branch and Tag Management

Control which branches and tags are preserved.

# In your config.yml
output:
  keep_branches: ["main", "develop", "feature/new-feature"]
  keep_tags: ["v1.0.0", "v1.1.0"]
  delete_other_branches: true
  delete_other_tags: true

Troubleshooting

Common Issues

Permission Denied

Make sure you have write permissions to the output directory.

# Check permissions
ls -la /path/to/output/directory

# Fix permissions if needed
chmod 755 /path/to/output/directory
Git Repository Not Found

Ensure you're in a directory with a .git folder.

# Check if it's a git repository
ls -la .git

# If not, initialize git first
git init
Configuration File Not Found

Run shomei init to create the configuration file.

# Create default configuration
shomei init

# Check the config file
cat ~/.shomei/config.yml
