# Shōmei Documentation

This folder contains the GitHub Pages website for shōmei.

## 🚀 Quick Start

The website is automatically deployed to GitHub Pages when you push to the `main` branch.

## 📁 Structure

- `index.html` - Main landing page with hero section and documentation
- `_config.yml` - Jekyll configuration for GitHub Pages
- `assets/` - Images, CSS, and other static assets (create this folder for logos)

## 🌐 View the Site

Once deployed, your site will be available at:
`https://petarran.github.io/shomei`

## 🔧 Customization

### Adding Your Logo
1. Create an `assets/` folder
2. Add your logo images (PNG, SVG, etc.)
3. Update the HTML to reference your logo

### Updating Content
- Edit `index.html` to change the website content
- The site uses vanilla HTML/CSS/JS for maximum compatibility
- No build process required - just push to GitHub!

### Styling
- All styles are in the `<style>` tag in `index.html`
- Uses CSS custom properties for easy color customization
- Responsive design that works on all devices

## 📱 Features

- ✅ **Hero Section** with Japanese branding
- ✅ **Responsive Design** for mobile and desktop
- ✅ **Interactive Elements** (tabs, smooth scrolling)
- ✅ **Modern UI** with gradients and animations
- ✅ **SEO Optimized** with proper meta tags
- ✅ **Fast Loading** - no external dependencies except fonts

## 🎨 Design System

- **Primary Colors**: Indigo (#6366f1) and Purple (#8b5cf6)
- **Typography**: Inter for body text, JetBrains Mono for code
- **Animations**: Subtle fade-in effects and hover states
- **Layout**: CSS Grid and Flexbox for modern layouts

## 🚀 Deployment

1. **Push to main branch** - GitHub Pages automatically builds
2. **Check Actions** - Monitor the deployment in GitHub Actions
3. **Visit your site** - Available at `https://petarran.github.io/shomei`

## 🔍 Troubleshooting

- **Site not updating?** Check GitHub Actions for build errors
- **Styling issues?** Verify the `_config.yml` is correct
- **Images not showing?** Make sure they're in the `assets/` folder
