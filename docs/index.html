Installation

Get started with shōmei in minutes

brew install petarran/shomei/shomei
pip install shomei
git clone https://github.com/petarran/shomei.git
cd shomei
pip install -e .

Quick Start

Process your first repository in minutes

# Initialize shōmei in your repository
shomei init

# Analyze what will be processed
shomei analyze . --config config.yml

# Process and sanitize your repository
shomei process . --config config.yml

# Push to your personal GitHub repo
git push origin main

Configuration

Create a config.yml file to customize the sanitization process:

# config.yml
author:
  name: "Your Name"
  email: "your.email@example.com"

sanitization:
  strip_files: true
  placeholder_text: "[CONTENT_STRIPPED]"
  keep_structure: true

output:
  directory: "./sanitized_repo"
  create_new_repo: true
